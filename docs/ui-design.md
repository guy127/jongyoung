# UI Design — jongyoung

ออกแบบหน้าจอด้วย Claude Design ก่อนแล้วจึงทำจริงบน Next.js

**ลิงก์ mockup ทุกหน้า:** https://claude.ai/artifact/Cb7eGqYexzQd73X6AiqvKR

## หน้าที่ออกแบบไว้

| หน้า | เนื้อหา |
|---|---|
| หน้าแรก | ค้นหา (วัน/เวลา/จำนวนคน) + การ์ดร้านพร้อมปุ่มเวลาว่าง |
| หน้าร้าน | รูป + ปุ่มเวลา + ฟอร์มจอง + กติกายกเลิก + รีวิว |
| หน้ายืนยันการจอง | เลขที่จอง เวลา ยกเลิกได้ถึงกี่โมง |
| การจองของฉัน | แยก tab กำลังจะถึง / ผ่านมาแล้ว / ยกเลิกแล้ว |
| จัดการร้าน (owner) | ตารางการจองรายวันทำการ + แถบที่นั่ง |
| สถานะพิเศษ | ที่นั่งไม่พอ (409), ร้านเต็มทั้งรอบ, มือถือ 375px |

## แนวคิดหลัก

- เลือกเวลาได้ตั้งแต่หน้าแรก ไม่ต้องกดเข้าร้านทีละร้าน — 2 แท็ปถึงหน้าจอง
- กติกายกเลิกแสดงก่อนกดจอง ไม่ใช่หลังจองเสร็จ
- ปุ่มที่กดไม่ได้ไม่ซ่อน แต่ทำให้จางพร้อมบอกเหตุผล
- ฝั่งลูกค้าเน้นตัดสินใจง่าย ฝั่งเจ้าของร้านเน้นสแกนเร็ว (ตาราง ความหนาแน่นสูง)
- เวลาหลังเที่ยงคืนติดป้าย "(เช้าวันที่ n)" ทุกที่
